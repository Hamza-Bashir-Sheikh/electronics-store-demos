# Electronics Store Website Concepts

A portfolio demo with two responsive e-commerce front-end concepts for an electronics and mobile accessories store.

## Demo pages
- `index.html` — portfolio landing page
- `modern-tech-store.html` — navy and blue store concept
- `smart-shopping-store.html` — white and orange store concept

## Demo features
- Product catalogue and category filters
- Product search
- Shopping cart and quantity controls
- Demo checkout and order confirmation
- Responsive layout

## Important
This is a front-end demonstration only. No real payment gateway, customer order backend, courier booking, PostEx API, or live shipment tracking is connected.
